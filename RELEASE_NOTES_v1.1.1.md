# BTCZ Tools v1.1.1 🪟

**BTCZ Tools now runs on Windows without installing anything.**

## ⬇️ Download

Grab **`BTCZ-Tools.exe`** from the Assets below, double-click, and you're mining-aware.
No Python, no virtualenv, no setup. Your data (addresses, settings, history) is saved
right next to the executable.

> First launch needs an internet connection to download the BTCZ logo and fetch live data.
> Windows SmartScreen may warn on an unsigned app — click "More info" → "Run anyway".

## 🔧 What's new

- 🪟 **Standalone Windows executable** (built with PyInstaller).
- 💾 **Data persists** next to the `.exe` between runs.
- 🎨 **Sharper icon** (16→256 px) for Windows 10/11.
- Fixes for windowed-mode logging.

Everything from v1.1.0 (the Mining Assistant, 8 modules, live pool stats, 4 languages) is included.

## 🧑‍💻 Run from source

```bash
git clone https://github.com/RGBTCZ/BTCZ-Tools.git
cd BTCZ-Tools
./run_btcz.sh
```
