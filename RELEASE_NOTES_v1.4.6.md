# BTCZ Tools v1.4.6 ⛏️

**Today's miner emission, front and centre on the Dashboard.**

## ⬇️ Download

Grab **`BTCZ-Tools.exe`** from the Assets below, double-click, done.
Already on v1.2.0+? The app will offer this update for you the next time you launch it. 🚀

## 🔧 What's new

- ⛏️ **Emission chip in the Dashboard header** — a compact, premium pill showing how many BTCZ have been paid to miners since local **midnight** (with the block count), right at the top of the app so it hits you the moment it opens. It's the same live figure as the Network Explorer's emission card (real blocks × post-Canopy 2,500).

Everything from v1.4.5 (the Network Explorer emission card) is included.

## 🧑‍💻 Run from source

```bash
git clone https://github.com/RGBTCZ/BTCZ-Tools.git
cd BTCZ-Tools
./run_btcz.sh
```
