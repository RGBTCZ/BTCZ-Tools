# BTCZ Tools v1.4.0 🔔

**BTCZ Tools becomes an always-on companion: system tray + desktop alerts.**

## ⬇️ Download

Grab **`BTCZ-Tools.exe`** from the Assets below, double-click, done.
Already on v1.2.0+? The app will offer this update for you the next time you launch it. 🚀

> First launch needs an internet connection to download the BTCZ logo and fetch live data.
> Windows SmartScreen may warn on an unsigned app — click "More info" → "Run anyway".

## 🔧 What's new

- 🔔 **Notifications center** — a new tab to turn on and tune four alerts, see a history of what fired, and send a **test notification**.
- 🖥️ **Background monitor** — the app quietly watches and pushes a desktop toast on the right moment (no spam):
  - 💶 **Price target** reached (rising / falling / any)
  - 💰 **Payment received** on a tracked address
  - 🖥️ **Rig offline** — a worker's hashrate drops to 0 (with a "back online" notice)
  - 📈 **Difficulty jump** past a threshold you choose
- 📥 **System tray** — closing the window now minimizes BTCZ Tools to the tray and keeps it monitoring (with a one-time heads-up the first time). Right-click the tray icon → **Show** / **Quit**.

That's **10 modules** now. Everything from v1.3.0 (Halving countdown, Holder cockpit, shareable card, auto-updater) is included.

## 🧑‍💻 Run from source

```bash
git clone https://github.com/RGBTCZ/BTCZ-Tools.git
cd BTCZ-Tools
./run_btcz.sh
```
