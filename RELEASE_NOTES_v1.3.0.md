# BTCZ Tools v1.3.0 ⏳

**A premium countdown to the next BitcoinZ halving.**

## ⬇️ Download

Grab **`BTCZ-Tools.exe`** from the Assets below, double-click, done. No Python, no setup.
Already on v1.2.0? The app will offer this update for you the next time you launch it. 🚀

> First launch needs an internet connection to download the BTCZ logo and fetch live data.
> Windows SmartScreen may warn on an unsigned app — click "More info" → "Run anyway".

## 🔧 What's new

- ⏳ **Halving tab** — a clean, live countdown to the next halving: **days / hours / minutes / seconds** ticking in real time, the estimated date, a progress bar through the current era, and the reward transition (**current reward → reward after halving**, with the miner share on each side).
- 100 % **on-chain** and deterministic: computed from the block height and the emission schedule (halving every 840 000 blocks) — no extra data source, always in sync with the network.

Everything from v1.2.0 (Holder cockpit, shareable card, auto-updater, on-chain supply) is included — that's now **9 modules**.

## 🧑‍💻 Run from source

```bash
git clone https://github.com/RGBTCZ/BTCZ-Tools.git
cd BTCZ-Tools
./run_btcz.sh
```
