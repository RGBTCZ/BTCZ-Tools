# BTCZ Tools v1.4.1 🔔

**A small polish on the notifications center.**

## ⬇️ Download

Grab **`BTCZ-Tools.exe`** from the Assets below, double-click, done.
Already on v1.2.0+? The app will offer this update for you the next time you launch it. 🚀

## 🔧 What's new

- 🗑️ **Delete alerts** — remove any entry from the history with its ✕, or wipe them all with **Clear all**.
- 💶 **Clearer price target** — the field now explains what to type, shows an example, and displays the **current BTCZ price** right below it so you know exactly what to enter.

Everything from v1.4.0 (system tray, background monitor, the four desktop alerts) is included.

## 🧑‍💻 Run from source

```bash
git clone https://github.com/RGBTCZ/BTCZ-Tools.git
cd BTCZ-Tools
./run_btcz.sh
```
